# rename_pdfs_easily

Renaming a lot of pdf files is takes a long time? <br/>
you can use this vibe-coded tool to rename them quickly and easily!

## How to use?
Clone the repo:
```
git clone https://github.com/yousif-saif/rename_pdfs_easily
```
First of all add all of your pdfs to the `./pdfs` folder

Then run the local flask server by running this command:
```
python app.py
```

Thats it!
